Madcow 5×5, explained

Madcow 5×5 is a three-day intermediate program built on Bill Starr’s 5×5. Sets ramp up to a heavy top set, and the top sets rise about 2.5% a week, with a new PR most Fridays.

What Madcow 5×5 is

Madcow 5×5 is a three-day intermediate strength program based on Bill Starr’s classic 5×5 training. It replaced session-by-session progress with weekly progress, so it is a natural step after a beginner program like StrongLifts or Starting Strength.

The week

Each day uses ramping sets: the weight climbs each set up to a heavy top set.

DaySquatPressPull
Monday (heavy)5 sets of 5 ramping to a top setBench, 5 sets of 5 rampingBarbell row, 5 sets of 5 ramping
Wednesday (light)Lighter ramp, top set below MondayOverhead or incline press, 4 sets of 5 rampingDeadlift, 4 sets of 5 ramping
Friday (PR day)4 ramping sets of 5, a heavy triple, then a back-off set of 8Bench, same patternRow, same pattern

Ramping sets usually rise in steps of about 12.5% of the top set. Friday’s triple is set slightly heavier than Monday’s top set, which makes it a new PR most weeks.

How progression works

Each week, the top sets rise by about 2.5%. Friday’s triple then becomes the next Monday’s top set of five. Because you start a few weeks below your best, the first weeks feel easy, and you pass your old records around week four or five.

Most lifters get roughly 8 to 12 weeks before weekly PRs stop. Plan your next program before that happens.

A sample Monday ramp

For a top set of 225 lb on squat, ramping in steps of about 12.5%:

5 (top)225 lb5

Weights are rounded to loadable numbers. Only the top set is hard; the ramp is practice.

Who it suits

Madcow suits lifters coming off a three-day beginner program who still want to squat three times a week and like a weekly record to chase. It is lower in volume than nSuns or PPL, so it fits lifters with limited time or recovery. If you want more muscle-building volume, add two or three short accessories at the end of each day.

Running it at home

Everything in Madcow uses a barbell, rack and bench, so it runs well in a garage gym. Limited plates make the 12.5% steps awkward; round each ramp set to the nearest weight you can load. Our warm-up calculator builds a plate-friendly ramp.

Common mistakes

  1. Starting at your current max. You skip the run-up that makes the program work.
  2. Treating Wednesday as a heavy day. It exists to help you recover for Friday.
  3. Skipping the back-off set. The Friday set of 8 adds valuable volume for very little fatigue.
  4. Running it after it stops working. Resets help once or twice. After that, move on.

What to run next

When weekly PRs stop, move to a program that varies volume and intensity across longer blocks, such as 5/3/1 Boring But Big or a block-periodized plan. See what to run after your program ends.

Frequently asked questions

Who created Madcow 5×5?

It grew out of Bill Starr’s 5×5 training and was popularized online by a lifter known as Madcow. It is often recommended as a first intermediate program.

How do I pick starting weights?

Start your Monday top sets several weeks below your current best, so the weekly increases have room to run. Many lifters start about four weeks back.

What do I do when I stall?

Repeat the week once. If you stall again, drop back a couple of weeks and build up again. When resets stop working, move to a program with planned blocks.

Why do the sets ramp up instead of staying at one weight?

Ramping sets act as warm-ups and practice while keeping fatigue low, so you can hit a heavy top set each session.
