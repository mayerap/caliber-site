How to import any spreadsheet program into Caliber

Export your program as Excel or CSV with one exercise per row and Exercise, Sets and Reps columns, then import it. Caliber also reads week, day, RPE or RIR, percentages, weights, rest, technique and notes.

How importing works

Caliber reads Excel files (.xlsx, .xls, .xlsm) and CSV files. Each row is one exercise on one day. Caliber finds the header row, reads each column by its name, and builds your weeks and days. You see a preview before anything is saved, with a count of weeks, days and exercises.

Only Exercise, Sets and Reps are required. Rows without sets or reps, like “Rest day” notes, are skipped, and the preview tells you how many.

Rules that make imports clean

  • One exercise per row. For back-off sets, add a second row for the same exercise right below the first.
  • Day names carry down. Write the day name once; rows below it belong to that day until the next name.
  • Percentages need maxes. If you use %1RM, add a tab named Maxes with Exercise and 1RM columns (an Excel file, since CSV has only one tab). Caliber turns each percentage into a weight from it.
  • RPE converts to RIR. RPE 8 becomes 2 reps in reserve. Use whichever your program uses.
  • Supersets: start names with a label like A1: and A2: to pair exercises.
  • Alternatives: a Substitution column gives Caliber your program’s own swaps, which it uses first when you train at home.

Programs you bought

Many popular programs are sold as spreadsheets by their coaches. You can import your own copy the same way: export the program tab as Excel or CSV and import it. If a column isn’t recognized, rename its header to a name from the table above. Your file stays yours; Caliber doesn’t share program content.

If something doesn’t import

  1. Make sure there is exactly one header row above the exercises, with an Exercise column.
  2. Check that Sets and Reps contain numbers, like 3 and 8-10.
  3. Remove merged cells in the header row.
  4. Split very complex sheets into one tab per block and import the tab you are about to run.

After you import

Check the preview, then save. Every day becomes a session on your plan. If a row has a percentage, Caliber turns it into a weight from your maxes. If the weight is blank and there is no percentage, you enter it in your first session, and your logged RIR or RPE takes it from there.

Bring your program to Caliber

Import once and every day becomes a live workout with rest timers, plate math and set-by-set adjustments from your RIR or RPE. When your program ends, Caliber can continue with six-week blocks built from your new numbers.

Frequently asked questions

Can I import a program I bought?

Yes. If you have the spreadsheet, export the program tab to Excel or CSV and import it. Caliber only reads your copy; nothing is shared.

What if my spreadsheet doesn’t use these column names?

Caliber recognizes common names for each column, such as Wk, Session, Load or %1RM. If a column still isn’t read, rename its header to one of the names below.

How do I write a set range like 6 to 8 reps?

Type it as 6-8. Caliber reads text, so Excel can’t turn it into a date.

How do I mark an AMRAP set?

Put the number of reps in Reps (for example 5) and write AMRAP in the Technique column. Caliber shows it as a last-set note.

How do back-off sets work?

Add another row for the same exercise right below the first, with its own sets and reps. Caliber keeps them together as one exercise with two set groups.
